# ShootChart UI仕様書

ミニバスケットボール（小学生）試合用ショットチャート記録アプリ。  
iPad専用・横向き固定・オフライン完結。

---

## 対象環境

| 項目 | 仕様 |
|---|---|
| デバイス | iPad のみ（iPhone 非対応） |
| 向き | ランドスケープ固定（左右両対応） |
| OS | iOS 17.0 以上 |
| データ保存 | SwiftData（オンデバイス、iCloud なし） |

---

## 画面一覧

| 画面 | ファイル | 役割 |
|---|---|---|
| ホーム | `HomeView.swift` | 試合一覧・新規作成 |
| 試合編集 | `GameEditView.swift` | 試合情報・メンバー登録 |
| ショットチャート | `ShotChartView.swift` | ショット記録メイン画面 |
| 集計 | `SummaryView.swift` | 選手別シュート集計 |

## 1. ホーム画面（HomeView）

### レイアウト

```
┌─ NavigationStack ───────────────────────────────┐
│  ShootChart                    [編集] [＋]       │
├─────────────────────────────────────────────────┤
│  vs チーム名                        [📊] [✏️]   │
│  2024年4月1日  🏀 12/20                         │
│  メモ（1行）                                     │
├─────────────────────────────────────────────────┤
│  ...                                             │
└─────────────────────────────────────────────────┘
```

### 試合行の要素

- **タイトル**: `vs {対戦相手名}`（bold, title3）
- **サブテキスト**: 日付（`ja_JP` ロケール）＋ シュート数 `🏀 成功数/合計`（shots が 0 件の場合は非表示）
- **メモ**: 1行表示（空の場合は非表示）
- **📊 ボタン**: 集計画面へ NavigationLink
- **✏️ ボタン**: 試合編集シートを開く

### ツールバー

- **編集ボタン**（topBarTrailing）: リスト行の削除・並び替えモード
- **＋ ボタン**（topBarTrailing）: 試合編集シートを開く（新規作成）

### 空状態

試合が 0 件の場合は `ContentUnavailableView`「試合がありません」を表示。

## 2. 試合編集画面（GameEditView）

シート（`.sheet`）として表示。

### レイアウト

```
┌─ NavigationStack ──────────────────┐
│  試合を作成 / 試合を編集            │
│  [キャンセル]          [保存]       │
├────────────────────────────────────┤
│ ▼ 試合情報                         │
│   日付    [2024/04/01]             │
│   対戦相手 [チーム名]               │
├────────────────────────────────────┤
│ ▼ メモ                             │
│   [テキストエディタ（最低80pt）]    │
├────────────────────────────────────┤
│ ▼ メンバー               登録済み N名 │
│   [CSVファイルを選択]              │
│   #4  山田太郎                     │
│   #5  佐藤花子                     │
│   ...                              │
│   ─ フッター（空時のみ）─          │
│   CSV形式：1行目をヘッダー...      │
└────────────────────────────────────┘
```

### バリデーション

- 「保存」ボタン: 対戦相手が空白のみの場合は disabled

### メンバーセクション

- 背番号の昇順でソート
- 表示項目: 背番号（`#N`）・名前のみ（学年は非表示）
- インポート成功後: 「インポート完了 N名登録」アラート
- インポート失敗後: 「インポートエラー」アラート（エラー詳細あり）

## 3. ショットチャート画面（ShotChartView）

メインの記録画面。HStack で左：コート、右：コントロールパネル。

### レイアウト

```
┌──────────────────────────┬──────────────────────┐
│                          │ [#4 山田 | 1Q | ○]   │ ステータスバー
│                          ├──────────────────────┤
│                          │  [  2P  ] [  FT  ]   │ ショットタイプ（40pt）
│       コート             ├──────────────────────┤
│     (CourtView)          │  ○ 成功   × 失敗     │ 結果トグル（72pt）
│                          ├──────────────────────┤
│                          │ 記録Q: 1Q 2Q 3Q 4Q   │
│                          │ 表示Q: 全Q 1Q 2Q...  │ Q セクション
│                          ├──────────────────────┤
│                          │ 選手                  │
│                          │ ┌──────────────────┐ │
│                          │ │ #4  山田太郎  ✓  │ │ 選手リスト
│                          │ │ #5  佐藤花子     │ │ （スクロール可）
│                          │ └──────────────────┘ │
│                          ├──────────────────────┤
│                          │ [↩ 直前取消][🗑 削除] │ アクションボタン
├──────────────────────────┴──────────────────────┤
│  [全員] [#4] [#5] [#10]  ...                    │ 表示選手フィルター（52pt）
└─────────────────────────────────────────────────┘
```

**コートエリア**: `maxWidth: .infinity / maxHeight: .infinity`  
**コントロールパネル**: 固定幅 280pt  
**表示選手フィルター**: コート直下、高さ 52pt（ショットが1件以上ある選手のみ表示。0件の場合はバー非表示）

### ナビゲーションバー

- タイトル: `{対戦相手}  {日付}` (.inline)
- topBarTrailing: 集計画面への NavigationLink（📊 アイコン）

### ステータスバー（パネル最上部）

常に現在の入力状態を表示:
- `#N 選手名`（選手未選択時は「選手未選択」）
- `| 1Q |`（現在Qをアクセントカラーで表示）
- `| ○ or ×`（成功=緑/失敗=赤）

### ショットタイプ（2P / FT）

- ステータスバーの直下
- ボタン高さ: 40pt
- 選択中: accentColor 背景・白文字
- 非選択: 枠線のみ
- 切り替えると選択ショットが解除される

### 結果トグル（○成功 / ×失敗）

- ボタン高さ: 72pt
- 選択中: 塗り潰し（成功=緑、失敗=赤）
- 非選択: 枠線のみ + 文字色

### Q セクション（記録Q + 表示Q）

右パネル内の同一セクションに **記録Q** と **表示Q** を並べて表示。

**記録Q（記録対象クォーター）**:
- 1Q / 2Q / 3Q / 4Q / OT1 / OT2 を1行に並列表示
- 選択中: accentColor 背景・白文字
- Qを切り替えると選択ショットが解除される

**表示Q（コート表示フィルター）**:
- 横スクロール: 全Q / 1Q / 2Q / 3Q / 4Q / OT1 / OT2
- 選択中: オレンジ背景（記録Qと色を区別）
- コート上のマーカー表示のみに影響（記録には影響しない）

### 選手リスト（記録選手の選択）

- `ScrollView` 内に `VStack`（残り高さすべてを使用）
- 各行: `#背番号`（22pt bold・幅54pt）＋ 選手名
- 選択中の行: accentColor 薄背景 ＋ 右端に ✓ アイコン
- 選手を切り替えると選択ショットが解除される

### 表示選手フィルター（コート直下）

- コートエリアの直下に配置（右パネル外）
- ボタン: 最小幅 54pt・最小高さ 44pt、横スクロール
- 「全員」+ 各選手の背番号（`#N`）
- 選択中: オレンジ背景・白文字
- コート上のマーカー表示のみに影響

### アクションボタン（常時表示）

| ボタン | 動作 | 無効条件 |
|---|---|---|
| 直前取消 | 最後に記録したショットを削除 | shots が空 |
| 削除 | 選択中のショットを削除 | ショット未選択 |

### ショット記録の操作フロー

1. 選手を選択（右パネル 選手リスト）
2. ショットタイプを選択（2P / FT）
3. 成功 or 失敗を選択（右パネル）
4. Qを確認・変更（右パネル 記録Q）
5. コート上の任意の位置をタップ → ショット記録

### ショット選択（削除用）

- 既存マーカーをタップ → 選択状態（黄色・大サイズ）
- 同じマーカーをもう一度タップ → 選択解除
- 「削除」ボタンで選択中のショットを削除

### 集計画面からの遷移

`SummaryView` の選手行をタップすると、その選手の `id` を `initialFilterPlayerId` として渡して遷移。表示選手フィルターがその選手に初期設定された状態で開く。

## 4. コート表示（CourtView）

### コート仕様

| 項目 | 値 |
|---|---|
| 表示方式 | SVG 画像（`Assets.xcassets/basketball-court.imageset/basketball-court.svg`） |
| SVG viewBox | 942 × 540 |
| コート境界 | x = 40–906、y = 39–504（Court enum の定数） |
| アスペクト比 | 942:540（SVG 全体）/ コート境界部分はレターボックス表示 |

### 座標系

- コート上の位置は正規化座標 `(x, y) ∈ [0.0, 1.0]` で保存
  - `x = 0.0`: 左ベースライン、`x = 1.0`: 右ベースライン
  - `y = 0.0`: 上サイドライン、`y = 1.0`: 下サイドライン
- `imageRect(in:)`: SVG 全体を 942:540 アスペクトでレターボックス表示
- `courtRect(in:)`: SVG 内のコート境界（ショット配置・タップ判定に使用）
- 画面サイズ変更時も座標は変化しない

### ショットマーカー

| 状態 | 形状 | 色 | サイズ |
|---|---|---|---|
| 2P 成功（通常） | ○（円の枠線） | 緑 | 32pt |
| 2P 失敗（通常） | ×（中央ギャップあり） | 赤 | 32pt |
| FT 成功（通常） | ○（円の枠線） | 青 | 32pt |
| FT 失敗（通常） | ×（中央ギャップあり） | オレンジ | 32pt |
| 成功（選択中） | ○（枠線＋薄い塗り） | 黄 | 40pt |
| 失敗（選択中） | ×（中央ギャップあり） | 黄 | 40pt |

- マーカー中央に背番号を表示（10pt / 選択時 12pt）
- × は中央に背番号のためのギャップを設ける（gap radius = fontSize × 0.9）
- 線幅: 通常 4pt、選択中 5pt
- タップ判定半径: 22pt

## 5. 集計画面（SummaryView）

NavigationLink で遷移（ホームの 📊 ボタンまたはショットチャートの 📊 ボタンから）。

### レイアウト

```
┌─ NavigationBar: 集計：{対戦相手} ────────────┐
│ Qフィルター: [全Q][1Q][2Q]...[OT2]           │
├───────────────────────────────────────────────┤
│ #    名前    2P        FT        合計  成功率  │ ←ヘッダー行
│ 4    山田    8/12      4/6       18    67%     │
│ 5    佐藤    6/12      2/4       16    50%     │
│ ...                                           │
├─ 合計 ──────────────────────────────────────── ┤
│ 全員         14/24     6/10      34    59%     │
└───────────────────────────────────────────────┘
```

### Qフィルター

- 横スクロール: 全Q / 1Q / 2Q / 3Q / 4Q / OT1 / OT2
- 選択中は accentColor

### 集計テーブル

| 列 | 幅 | 内容 |
|---|---|---|
| # | 44pt | 背番号（bold） |
| 名前 | 可変幅 | 選手名 |
| 2P | 80pt | FG 成功/試投（緑）例: `8/12`、0件は `—` |
| FT | 70pt | FT 成功/試投（青）例: `4/6`、0件は `—` |
| 合計 | 54pt | 総試投数（2P + FT） |
| 成功率 | 64pt | `(2P成功+FT成功) / 合計 × 100%`（0本時は「—`） |

- 背番号の昇順ソート
- Shot に記録された `playerNumber` / `playerName` を使用（選手削除後も表示可）

### 行タップ → 選手フィルター付き ShotChartView

- 各選手行は NavigationLink
- タップすると ShotChartView に遷移し、その選手のショットのみコート上に表示
- ShotChartView の「表示選手フィルター」で他選手への切り替えも可能

## データモデル

### Player（グローバルメンバー）

```
id: UUID
number: String      # 背番号（重複キーとして upsert に使用）
name: String        # 選手名
grade: String?      # 学年（インポートのみ、画面には非表示）
createdAt: Date
```

### Game

```
id: UUID
date: Date          # 試合日
opponent: String    # 対戦相手名
memo: String        # メモ（空可）
createdAt: Date
shots: [Shot]       # deleteRule: .cascade
```

### Shot

```
id: UUID
playerId: UUID      # Player.id（参照用、削除後も保持）
playerNumber: String  # 記録時点の背番号（非正規化）
playerName: String    # 記録時点の名前（非正規化）
quarter: Int        # 1=1Q, 2=2Q, 3=3Q, 4=4Q, 5=OT1, 6=OT2
x: Double           # コート正規化座標 0.0–1.0
y: Double           # コート正規化座標 0.0–1.0
isMade: Bool        # 成功=true / 失敗=false
shotType: String    # "field"（2P）または "freeThrow"（FT）、デフォルト "field"
createdAt: Date
game: Game?
```

## CSVインポート仕様

### ファイル形式

| 項目 | 仕様 |
|---|---|
| 文字コード | UTF-8（BOMなし推奨） |
| 区切り | カンマ（`,`） |
| 改行 | LF / CRLF どちらも可 |
| 1行目 | ヘッダー行（必須） |
| 列順 | 不問（列名で判定） |

### 列定義

| 列名 | 必須 | 説明 |
|---|---|---|
| `number` | ○ | 背番号（文字列）|
| `name` | ○ | 選手名 |
| `grade` | - | 学年（任意） |

### サンプル CSV

```csv
number,name,grade
4,山田太郎,6年
5,佐藤花子,5年
10,鈴木次郎,6年
```

### upsert ルール

- `number` が一致する Player が存在する場合は `name` / `grade` を上書き
- 存在しない場合は新規作成
- 空行・必須列が空の行はスキップ
